# 回答质量阶段二：实现与统一测试

## 本次实现

- `app/agent/answer_contract.py`：识别明确的指标与图形要求；不支持的额外指标或图形先澄清。为适用的变化分析追加一次辅助 SQL 和一次程序核验，不启动无边界探索。
- `app/tools/driver_check.py`、`python_tool.py`：同范围销售额核对独立总额；订单量与客单价对称机械分解；零订单不计算未定义客单价，空值/负订单量拒绝分解。比较方向与基期、当期一致。
- `app/agent/context.py`、`scoped_analysis.py`、`loop.py`、`state.py`：追问范围和订单可加总确认继承；澄清补充恢复原业务问题；实际完成必要工具后才允许生成完成报告。时间图标签跟随粒度。
- `app/agent/report_facts.py`、`report_presentation.py`、`report_fallback.py`、`prompts.py`、`prompt_context.py`：区分变化贡献、数学分解、关联与因果；提示一致降幅可能只是基数差异。减少重复尾段、压缩已核验辅助明细的模型视图；关键辅助计算漏写时补充摘要，原始工具记录仍在本轮 API `steps` 中。
- `tests/test_answer_quality.py`：针对上述边界的本地检查。前端样式、上传流程、数据库权限与既有记录不改动。

## 能力边界

1. 主流程仍是单表、可加总指标、明确比较范围。不会宣称任意多指标或跨表问题都已支持。
2. 联合订单核验当前要求主指标是可识别的销售额/营收字段；不擅自把表行数当订单数。自定义表需确认订单记录互斥、可求和；确认保留在同表追问范围中。
3. 自动供货查证仅适用于已知口径的项目演示表。其他表先确认字段语义。缺货使用记录最小/最大值、不同值数量及状态，不推断缺货自然日总数。
4. 机械分解不是因果识别；客单价也不是商品售价。报告提示与数字覆盖补充不能证明每句模型回答正确。
5. 辅助链路固定增加一次 SQL、一次 Python；明确要求另一种已支持图形时可增加一个图表步骤。主分析仍受只读校验、行数与超时限制；不增加报告失败后的模型续写。

## 统一手动测试（7 轮，用户执行）

打开原工作台 <http://127.0.0.1:8501>，新建会话，逐轮发送。后台需已有项目电商演示表；正式 UI 不新增演示入口。

### 1. 趋势与渠道拆解

> 使用 public.demo_ecommerce_orders，分析 2026 年 1 至 3 月销售额的月度变化，按 sales_amount 求和，并按渠道拆解每次变化的主要来源，画折线图和贡献图。

检查：趋势、1→2 与 2→3 月渠道拆解都执行；不能只给总体趋势，再说渠道未查询，却标为完成。两种实际图表在相应正文位置展示。

### 2. 原因查证

> 为什么 2026 年 2 月销售额比 1 月下降？按渠道归因，同时核验订单量、客单价及表内供货记录，画贡献图。

检查：独立总额 666,000→652,300，净减少 13,700；线下门店 -37,000，线上与第三方合计抵消 +23,300。订单和客单价是本轮查询计算，不能只建议下次查。供货线索不能被写成已证明的因果。

### 3. 下钻但不误判异常

> 继续看线下门店，沿用指标和比较时期，按品类下钻，核验订单量与客单价，看看是否某一品类异常下降。

检查：线下 200,000→163,000；三个品类销售额自身均下降 18.5%。电脑贡献金额最大不能被说成它独有的异常；贡献率 55% 与自身降幅 18.5% 要分开。

### 4. 范围继承

> 沿用当前表、指标和筛选条件，查看覆盖刚才两个比较时期的月度走势，并画折线图。

检查：仍在线下，只覆盖 1、2 月；不能偷偷加入 3 月或改成全渠道。

### 5. 回到总体

> 取消全部筛选，回到总体，比较 2026 年 2 月和 1 月销售额，按渠道归因，并核验订单量和客单价。

检查：回到总体，不残留线下筛选；总额与第 2 轮一致，但必须重新查数。

### 6. 不支持的要求先澄清

> 同时比较销售额、订单量和利润的变化，并画饼图。

检查：缺少利润口径或不支持的图形要说明并澄清，不伪造利润，不悄悄换成柱状图后宣布全完成。

### 7. 澄清后继续原需求

> 先只比较销售额和订单量，仍按渠道拆解，图表改为贡献柱状图，比较 2026 年 2 月与 1 月。

检查：执行限定后的需求，报告简洁但不省略关键证据。保持当前会话与数据表。

如遇未完成，保留该轮并展开错误详情，不连续重发。模型网络故障仍可能发生；本次没有进行付费模型复测，以上是待用户执行的验收清单，不是已通过的真实回答报告。
