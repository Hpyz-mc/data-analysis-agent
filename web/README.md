# 数据分析工作台

这是项目正式前端，不是独立样稿。React + TypeScript 构建页面，Nginx 提供静态资源及同源 API 代理，默认入口 http://127.0.0.1:8501。旧 Streamlit 已移除。

## 运行

在项目根目录运行：

```bash
docker compose up -d --no-deps --build api ui
```

前提是项目数据库已经运行。首次启动整个项目请使用根目录 README 的部署步骤。更新前端不需要删除数据卷或重新导入数据。

本地开发在 `web/` 目录运行：

```bash
pnpm install --frozen-lockfile
pnpm dev
```

开发入口为 http://127.0.0.1:8503，`/api` 和 `/health` 默认代理至 http://127.0.0.1:8001。构建使用 `pnpm build`。前端不读取根目录 `.env`，不存储模型密钥或数据库连接串。

## 真实交互

- 打开页面读取最近会话和已登记数据集；请求失败显示错误及重试入口。
- 新会话首次发送时不传 ID，历史会话自动携带后端 ID。
- 展示 SSE 的真实阶段及回答增量；仅在收到有效且已持久化的 `result` 时结束等待，不将草稿当成完成结果。启用会话时先接收 `session` 事件，即使第一轮出错也能查看历史。
- 停止接收、断流或失败会保留当前页面已收到的片段，并明确标为未完成，不展示其图表或追问建议。片段不额外写入数据库，刷新后以历史为准。停止接收不能保证立即终止正在进行的模型请求，也不会撤回已发生的消耗。
- 未完成轮次提供“查看最新历史”及“编辑后重试”；后者只填回问题和数据选择，须确认发送，不自动重试。会话忙、超时、预算不足及连接异常分别给出提示。
- 图表使用后端实际生成的 PNG，并就地展示在正文图片、链接或图表地址的引用位置，同一张图不重复追加到末尾。旧回答若只有一张图和一个明确的图表小节，也会插入该小节；缺少明确位置或多图对应不清时才保留为末尾附件。仅渲染本轮 API 图表记录，不将模型编造的图片地址当作执行证据；历史恢复同样生效。
- 数据上传需确认；选文件后展示文件名、大小并校验格式、空文件和 20 MB 上限。导入结果持续显示真实行列数、版本表名及截断提示，重复文件可使用已有版本，不覆盖旧表。
- 数据集列表支持按文件名、表名或字段搜索，预览最多 3 行并可横向滚动。当前选择在管理页和聊天输入区标明；选择数据开始分析会开启新会话，原会话保留。历史会话删除需确认，不提供恢复功能。
- 正式界面不提供演示表加载或预设测试问题，内置演示数据表不出现在可选列表中；数据库表与已有会话不因此删除。
- Token 及耗时仍在 API 响应中，聊天界面不额外展示这些统计。

`src/main.tsx` 是工作台交互，`src/api.ts` 是 API/SSE 客户端，`src/DatasetsPanel.tsx` 与 `src/datasets.ts` 负责数据集展示及文件校验，`src/datasets.css` 是数据集管理样式。`src/styles.css` 与 `src/live.css` 是基础样式，`src/refinements.css` 调整文字可读性和紧凑首页布局，`nginx.conf` 是部署代理。空白首页与已有对话均保留底部输入区。

## 轻量客户端检查

Node 22 支持类型剥离时运行：

```bash
node --experimental-strip-types --test tests/api.test.mjs tests/datasets.test.mjs tests/chatStatus.test.mjs tests/reportCharts.test.mjs
```

用模拟响应检查 Unicode/分块 SSE、终止错误、缺失完成事件、409 和图表路径。不调用付费模型。它不替代浏览器验收或模型分析准确性验收。

本项目没有登录鉴权或租户隔离，仅绑定本机使用；不要开放到公网。
