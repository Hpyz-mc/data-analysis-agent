# 发布收尾：三项定向修复

日期：2026-10-09。没有扩大模型预算、增加分析类型或调用付费模型；没有删除业务表、会话或图表。

## 修复

1. `app/tools/sql_validator.py` 增加分析函数白名单，默认拒绝未知函数、动态 SQL 与 XML 导出函数；函数显式 schema 只允许 `pg_catalog`。`app/agent/source_scope.py` 在调用工具前复用该检查，`app/tools/sql_tool.py` 将查询函数解析顺序改为 `pg_catalog, public`。平台自己的设置/锁 SQL 不经模型查询入口。
2. `app/agent/clarification.py` 将明确表名、字段更正应用到本轮任务，避免把旧冲突原样重复拼接；保留原指标目标和时间文字。普通日期/口径补充仍保留原问题。新更正本身与界面选表冲突时仍澄清，不能借此绕过选表限制。
3. `app/session/store.py` 使用双整数保护锁（独立于会话 UUID 锁空间）：活跃分析、单会话删除持共享锁，批量清空持独占锁；获取失败返回忙碌状态/HTTP 409，连接关闭释放锁。批量清空不会中途删除活跃轮次。前端确认文案明确仅删除会话记录，不自动删除已有 PNG。
